# 수익화 아이디어

이 문서는 사업 가설이다. 아래의 유료 상품·가격·로드맵은 확정된 판매 약속이 아니며, 아직 검증된 매출·전환율·원가 데이터가 없다.

## 현재 구현된 기반

Ko-fi 후원 링크와 웹훅, 서버의 결제 기록 저장, 인증 사용자와 후원 기록을 대조하는 API, 후원 회원 표시가 있다. `guest`, `free`, `supporter` 상태는 존재하지만 본격적인 유료 권한·기간 만료·구독 청구 시스템으로 구현되어 있지는 않다.

현재 후원 판정은 인증 사용자의 검증된 이메일과 철회되지 않은 결제 기록을 기준으로 한다. 이메일이 다르면 매칭되지 않을 수 있고, 구독 결제가 기록되었다는 사실만으로 기간 만료 정책이 구현되는 것은 아니다. 후원 회원에게 게시판 관리자 권한을 부여하지 않는다.

## 제품 가치를 지키는 원칙

사용자가 소유한 파일을 열거나 기존 독서 기록을 확인하는 기본 경험은 안정성과 신뢰의 중심이다. 수익 모델은 지속적인 유지보수·편의·지원의 가치로 검증한다. 계정·Neon 기술은 수익화 성과와 관계없이 프로젝트의 기술적 구성 요소로 유지한다.

## 후보 모델

| 아이디어 | 사용자에게 제공하는 가치 | 필요한 추가 구현 | 주요 검증 |
| --- | --- | --- | --- |
| 자율 후원 | 지속 개발을 응원하고 후원 상태 표시 | 매칭 안내, 철회·환불 운영 절차 | 후원 확인 성공률·지원 문의 |
| 유료 편의 패키지 | 정교한 보기 프리셋·테마·레이아웃 모음 | 라이선스·에셋 관리, entitlement | 무료 경험의 품질과 실제 선호 |
| 로컬 정리 고급 도구 | 대규모 자료의 규칙·메타데이터 작업 편의 | 미리보기·복구·안전한 일괄 작업 | 파일 보존·작업 시간·지원 비용 |
| 선택적 설정·메타데이터 동기화 | 여러 장치에서 보기 설정·독서 위치 유지 | 동기화 모델, 충돌 해결, 저장·탈퇴 정책 | 사용자 동의·원가·충돌률 |
| 팀·기관 지원 | 합법적으로 보유한 자료의 운영·설치 지원 | 배포·업데이트·지원 범위·계약 | 유지보수 시간과 계약 수요 |

현재 파일 클라우드 업로드, 동기화 구독, 프리셋 판매, 기관용 관리 기능은 구현되어 있지 않다. 외부 플러그인 마켓플레이스도 현재 제공 기능이 아니다.

## 추천 검증 순서

첫 단계는 무료 핵심 기능의 재생·스캔 안정성과 자율 후원 확인 흐름을 마무리하는 것이다. 그다음 사용자 요청에서 반복되는 편의 문제를 수집하고, 소규모 기능 패키지의 지불 의향을 확인한다. 저장 비용과 계정 운영이 커지는 동기화 구독은 그 이후의 가설로 둔다.

임의의 정액을 현재 적정 시장가격이라고 제시하지 않는다. 일회성·정기 후원, 편의 상품, 지원 계약을 서로 다른 실험으로 보고 실제 유지보수 비용과 사용자 반응으로 가격을 결정한다.

## 손익과 지표의 틀

```text
기간 순기여 = 매출 - 결제·플랫폼 비용 - 서버·저장 비용 - 환불 - 지원 인건비
지원 비용/회원 = 기간 지원 시간 × 시간당 비용 ÷ 지원 대상 회원 수
후원 확인 성공률 = 자동으로 매칭된 유효 후원 건수 ÷ 확인 대상 유효 후원 건수
```

매출보다 먼저 작품 열기 성공률·데이터 보존·오류 재현률·지원 소요 시간을 기록한다. 제품 분석을 추가한다면 개인 파일명·폴더 경로·본문·토큰을 수집하지 않는 최소 설계와 동의 절차를 마련해야 한다. 현재 원격 제품 분석 수집 구현을 전제하지 않는다.

## 상용화를 위한 별도 과제

| 과제 | 현재와의 차이 |
| --- | --- |
| 권한 모델 | 현재 supporter 표시는 완전한 유료 entitlement가 아님 |
| 구독 기간 | 시작·종료·갱신·유예·취소 정책을 추가해야 함 |
| 환불·철회 | `revoked_at` 저장 필드만으로 운영 프로세스가 완성되지 않음 |
| 이메일 매칭 | 결제 이메일과 계정 이메일 불일치의 안전한 지원 절차 필요 |
| 결제 상태 변경 | 중복 웹훅, 지연, 취소 이벤트와 재처리 정책 필요 |
| 개인정보 | 보관 기간·삭제 요청·접근 권한·로그 정책 필요 |
| 라이선스 | 앱 라이선스와 포함 바이너리의 배포 조건을 먼저 확정해야 함 |
| 유통 | 서명, 설치·업데이트·롤백·지원 정책은 별도 검증 필요 |
