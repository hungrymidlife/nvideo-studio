## 문서의 상태 표현

- **구현**: 해당 동작을 수행하는 코드가 현재 저장소에 존재함
- **자동 검증**: 명시한 명령 또는 실행 파일 자체 검증에서 성공 결과를 확인함
- **사용자 확인 중**: 실제 장치·계정·파일로 확인이 필요하거나 이슈가 보고됨
- **제안**: 제품 아이디어이며 현재 구현·계약·가격 약속이 아님

## 범위와 중요한 차이

과거 인수인계의 요구사항에 있던 이메일 가입 UI와 댓글은 현재 코드에서 완료 상태를 확인할 수 없습니다. 계정 프로필은 조회·표시 중심이며 편집 기능은 별도 과제입니다. 문서의 기능 목록은 과거 계획보다 현재 코드와 검증 근거를 우선합니다.

현재 열린 검증용 DEV 실행은 별도의 SQLite·WebView 데이터 경로를 사용합니다. 이 실행에서 만든 루트·설정은 일반 실행의 사용자 DB와 같다고 가정하면 안 됩니다. 일반 배포본의 기본 데이터 경로는 변경하지 않았습니다.
