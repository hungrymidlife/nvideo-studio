# UI와 UX 설계

## 화면 구성

데스크톱 셸은 왼쪽 탐색, 상단 계정·상태·테마 조작, 중앙 기능 화면, 공통 대화상자로 구성한다. 로컬 책장은 루트 → 작가 → 작품의 계층을 표현하고 Reader를 열었다 닫아도 탐색 맥락을 이어간다.

| 영역 | 설계 의도 |
| --- | --- |
| 사이드바 | 제품의 네 가지 사용자 기능을 지속적으로 노출 |
| DEV 플러그인 관리 | 개발자 기능을 별도의 대화상자로 제공 |
| 책장 카드·목록 | 표지 중심 탐색과 텍스트 중심 탐색을 모두 지원 |
| 검색·태그·정렬 | 같은 목록 범위 안에서 탐색 조건을 조합 |
| Reader | 작품 내용에 집중하면서 도크·보기 설정을 필요할 때 노출 |
| 공통 확인 대화상자 | 대상과 결과를 읽고 변경을 실행하도록 구성 |

## 디자인 토큰

현재 CSS의 의미 기반 변수를 재사용한다. 다음은 실제 소스 값이며 별도 디자인 도구의 독립 규격이라고 주장하지 않는다.

| 토큰 | Dark | Light |
| --- | --- | --- |
| `--background` | `#181818` | `#f4f7fc` |
| `--sidebar` | `#1b1b1b` | `#ecf2fa` |
| `--panel` | `#202020` | `#ffffff` |
| `--text` | `#f0f0f0` | `#1e314d` |
| `--muted` | `#b0b0b0` | `#64758b` |
| `--accent` | `#43a7f5` | `#006bb9` |
| `--green` | `#43d8ad` | `#1e9875` |
| `--danger` | `#f18e9a` | `#c33d53` |

글꼴은 Segoe UI Variable, Segoe UI, Noto Sans KR, 시스템 sans-serif 순서로 지정한다. 모든 글꼴 파일을 애플리케이션에 포함한다는 뜻은 아니다. Lucide 아이콘을 사용하며 상태는 색뿐 아니라 문구·버튼·진행 정보로도 전달한다.

## 탐색 맥락 보존

책장으로 돌아왔을 때 페이지와 필터가 같아도 카드 포커스가 잘못되면 키보드 흐름이 끊어진다. 선택 ViewModel은 돌아갈 작품 ID·페이지·index를 저장하고 목적지 목록의 로딩 완료를 확인한 후 포커스를 복원한다.

Reader 내부에서 다른 작품으로 이동했다면 처음 연 작품이 아니라 마지막 작품을 기준으로 복귀 위치를 찾는다. 필터 결과에 없는 작품은 기존 목록 위치를 유지하는 안내를 제공한다.

## Reader의 보기 모드

manga, webtoon, auto 프리셋을 분리해 layout, fit, zoom, 여백·방향 등을 저장한다. 모드를 전환하는 동작과 프리셋 자체를 저장하는 동작이 불필요하게 서로 덮어쓰지 않도록 한다. 긴 웹툰과 대용량 작품은 표시 범위·페이지 목록 가상화와 연결한다.

실제 DPI, 화면 크기, 긴 페이지, 손상된 이미지와 서로 다른 영상 장치는 사용자 테스트에서 확인해야 한다. 현재 모든 환경의 접근성·대비 기준을 인증받았다고 표현하지 않는다.

## 안전한 조작과 실패 경험

- 파일 이동·휴지통 작업은 대상과 결과를 확인하는 흐름으로 제공한다.
- 외부 플러그인 설치·게시자 신뢰 변경은 별도 확인 대화상자를 사용한다.
- 바쁜 상태에서 중복 실행을 막고 오류를 해당 기능 안에서 보여준다.
- 닫기 버튼과 Alt+F4는 트레이 유지·완전 종료를 선택하도록 한다.
- 로그인 취소는 OAuth 완료를 기다리지 않고 UI를 정리할 수 있어야 한다.
- 네이티브 잠금 오류나 프로세스 장애는 React Error Boundary로 해결되는 문제와 구분한다.

## 수동 테스트 관찰 항목

현재 사용자가 직접 기능 테스트를 진행한다. 스캔 중 취소, Reader를 닫은 뒤 카드 위치, 만화·웹툰 모드 전환, 다크·라이트, 네이티브 영상 위 오버레이, 멀티뷰·자막, 로그인 취소와 실패 문구를 우선 확인한다. 체크 결과는 [빌드·검증 문서](../engineering/07-build-and-validation.md)에 연결한다.
